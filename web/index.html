02 / MANDATO

Una capa de coordinación,
no otra autoridad.

El protocolo existe para reducir asimetrías: el propietario conserva el control, el minero conserva la decisión y cada afirmación importante deja una prueba verificable. RescueMesh no promete confirmaciones ni intenta sustituir el consenso.

Red activa — El prototipo solo admite entornos de prueba.
Mainnet — Bloqueada en configuración y ejecución.
Anuncios válidos — Firmados, temporales y limitados.
Trabajos públicos — Solo compromisos y valores agregados.

03 Protocolo

Cuatro pasos. Ningún punto de custodia.

Cada paso reduce la información compartida y conserva una ruta de verificación independiente.

  1. 01

    Sellar

    Los datos sensibles se cifran localmente. El manifiesto privado nunca entra en la API pública.

    owner → sealed store
  2. 02

    Comprometer

    Se publica una raíz salada, la economía agregada y una política con caducidad.

    bundle → commitment
  3. 03

    Evaluar

    El minero compara el valor verificable con el coste real del espacio desplazado.

    gain ≥ marginal cost
  4. 04

    Demostrar

    El trabajo aceptado produce un recibo firmado, ligado al trabajo y resistente a duplicados.

    share → proof of help

05 Modelo de seguridad

La confianza se sustituye por límites.

Los controles son explícitos, comprobables y cerrados por defecto. Las limitaciones conocidas forman parte del producto, no de la letra pequeña.

CTRL / 01

Interfaz local

La administración se limita a loopback. Las escrituras requieren autorización y comparación temporalmente constante.

CTRL / 02

Superficie mínima

No existe un endpoint para transacciones raw. Tamaño, frecuencia, métodos y campos están restringidos.

CTRL / 03

Criptografía separada

Cifrado AES-256-GCM, firmas Ed25519 y secretos con funciones distintas para reducir impacto y reutilización.

CTRL / 04

Activación imposible

Mainnet y la difusión están sin implementar. Ningún indicador de configuración puede habilitarlos accidentalmente.

Frontera actual Riesgo declarado

Validez de plantillas ocultas

Un minero no puede validar por completo transacciones que permanecen selladas. Hasta disponer de pruebas de validez sin revelación, debe usar un coordinador local de confianza o rechazar el trabajo.
