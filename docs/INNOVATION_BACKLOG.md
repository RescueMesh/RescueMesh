# Innovation backlog

Ideas are hypotheses until measured and reviewed.

1. **Proof-carrying sealed templates** — prove consensus validity and a minimum fee floor while the pool remains blind to transaction data.
2. **Reciprocal rescue insurance** — allocate future queue priority from verified work rather than money or identity.
3. **Marginal blockspace cooperative** — coordinate only when inclusion has non-negative expected value for miners.
4. **Ephemeral capability gossip** — signed short-lived onion announcements with anti-spam work and no persistent directory.
5. **Cross-pool portability** — one local template policy with DATUM, Stratum V2 and decentralized reward adapters.
6. **Private sponsor bundles** — optional independent transactions fund miner upside while a free rescue rides in the same sealed commitment.
7. **Proof-of-work service receipts** — reuse verified partial shares for auditable monitoring and mutual-insurance accounting without creating a token.
8. **Template diversity score** — measure how many independent policies contribute actual work without exposing their transaction sets.
9. **Stale-work recycling analysis** — study whether otherwise stale partial shares can safely contribute only to non-monetary cooperative reputation.
10. **Threshold coordinators** — split sealed manifest access across multiple operators so no single service can reveal it before confirmation. The 0.1 code includes a tested Shamir-style GF(256) primitive; network release policy remains research.

The Idea Lab combines these primitives and scores proposals for owner protection, miner value, decentralization, feasibility and security risk.
